## Fixed in this branch

### 1. Locale-dependent decimal formatting (i18n bug) — FIXED

`"%.1f".format(x)` / `"%.0f".format(x)` use `Locale.getDefault()`. On Persian, Arabic,
German and several other locales the decimal separator becomes `٫` / `,`, so an
English-language UI renders `12٫5 ms`, `8٫2 MiB/s`, and machine-oriented strings such
as `Autopilot • … gain 4٫5` are produced with the wrong separator.

Fixed with `String.format(Locale.US, …)` (+ `import java.util.Locale`) in:

### 2. `native/rankhelper/main.go` — wrong job count in the `done` event — FIXED

Jobs with an empty `ID`/`Config` are skipped in the worker loop, but the terminal
`done` event still reported `Jobs: len(batch.Jobs)`. A batch in which every job was
invalid reported a non-zero job count with zero results. The event now reports the
number of jobs actually executed.

## Reported, intentionally unchanged

- `scripts/update-core-lock.sh` pins the newest **prerelease** Xray tag; it fails
  cleanly when none exists, but the channel choice is worth a second look.
- `XrayManager.portAvailable()` binds only `127.0.0.1`; the reservation check could
  miss a conflict if a config ever binds `0.0.0.0`.
- `RankTargetScheduler` rotates from `networkKey.hashCode()`; an empty network key
  makes every unknown network share one rotation epoch (cosmetic).
- `SocksHttpClient.tunnelRttBatch` hardcodes CONNECT target port 443 (by design today).
